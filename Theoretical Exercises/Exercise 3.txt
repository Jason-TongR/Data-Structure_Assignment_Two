Exercise 3 : A data structure for anagram checking
    
    Our idea is :
        we will use HashMap to do this exercise.
        in our HashMap<String , Integer> , 
        the first arugment(key) is the appear times of each character in the word (id card)
            e.g. :  abc -> its id card is a1b1c1d0e0...z0
                    bac -> its id card is a1b1c1d0e0...z0
                    cba -> its id card is a1b1c1d0e0...z0
                    jason -> its id card is a1b0...j1...s1..o1..n1...z0
    
        the second arugment(value) is the add times of each id card in this Set
            e.g. :  we add 'abc' -> <a1b1c1d0......z0 , 1>
                    we add 'bca' -> <a1b1c1d0......z0 , 2>
